# Instructions projet — Creaprint

## Git

Ne jamais faire de commit sans permission explicite de l'utilisateur, même en fin de tâche. Toujours demander avant de commit.

## Rédaction

Interdiction absolue des tirets cadratin/demi-cadratin ("–", "—", le style "tiret qui fait IA"). Utiliser un tiret normal "-", une virgule, ou reformuler la phrase. Ça s'applique à tout texte écrit dans le code (contenu HTML/TS) et dans les réponses.
